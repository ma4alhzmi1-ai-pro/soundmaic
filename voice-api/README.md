# Soundmaic Voice API

خدمة وسيطة صغيرة لتطبيق Android. تحتفظ بمفتاح ElevenLabs على الخادم فقط، ولا تحفظ النصوص أو التسجيلات أو الصوت الناتج بعد اكتمال الطلب.

## المسارات

- `GET /health` — فحص الجاهزية.
- `GET /api/voices` — قائمة ملفات الصوت المتاحة.
- `POST /api/tts?profile=young_woman` — جسم JSON من الشكل `{ "text": "...", "speed": 1.0 }` ويعيد MP3.
- `POST /api/voice-convert?profile=young_man` — يمرر multipart/form-data إلى Speech-to-Speech ويعيد MP3.

تحتاج مسارات التحويل `POST /api/tts` و`POST /api/voice-convert` الترويسة `X-Soundmaic-Client: android`؛ أما `/health` و`/api/voices` فهما عامّان. هذه الترويسة ليست سرًا ولا تُعدّ مصادقة، لذا فالحدود الحالية للحجم والمعدل تخفف الاستخدام العرضي فقط ولا تمنع إساءة استخدام الخدمة العامة. يلزم إضافة Firebase App Check أو مصادقة موثوقة قبل الاعتماد الإنتاجي.

## إعداد الصوت الشابة

تستخدم طلبات `profile=young_woman` ملف الصوت المحدد في `ELEVENLABS_YOUNG_WOMAN_VOICE_ID` على الخادم. إذا لم يُضبط المتغير، يستخدم الخادم الصوت الافتراضي الحالي. ضع قيمة معرّف الصوت فقط بعد إنشاء الصوت وامتلاك الإذن، ولا تضع مفتاح ElevenLabs أو أسرارًا في تطبيق Android أو ملفات Git.

يعتمد تحديد عنوان العميل لأغراض الحد من المعدل على عدد وكلاء موثوقين (`TRUSTED_PROXY_HOPS`، الافتراضي 1). اضبطه وفق سلسلة الوكلاء التي يضيفها مضيف الخدمة، ولا تثق في قيمة يرسلها العميل مباشرة.
